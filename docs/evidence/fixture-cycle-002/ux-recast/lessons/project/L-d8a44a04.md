When a form refuses a submit, leave every value the person entered in place, say which field is wrong and how to make it acceptable in that field's own error slot, and move focus to the first field that needs correcting. Clearing the form or showing only a generic "check your details" line makes one mistyped character cost the whole request.

Seen on the contact-request fixture: the defective handler reset the form on validation failure (F1), named no field (F2) and left focus on the Send button (F3). The repair validates each field into its existing error slot, sets aria-invalid, never resets the form, and focuses the first invalid field; the flow test that failed before passes after.
